# Matriz Funcional, de Persistencia y de Pruebas — ATLOB ERP

**Fecha de corte:** 12 de noviembre de 2026 (`HEAD f0aa29d`)  
**Criterios de clasificación funcional:**
1. **Implementado y probado en entorno real (PG 18.6):** flujo completo conectado end-to-end contra PostgreSQL real y verificado con suite real sin `pg-mem`.
2. **Implementado y probado solo en memoria / estático / parcial:** servicio con persistencia parcial o `*_MEMORIA`, o flujo UI desconectado/con fallback estático.
3. **Implementado parcialmente:** backend o UI incompleto, ruta rota (`404`), regresión de compilación/lógica o persistencia solo en estado React / memoria.
4. **No implementado / demostrativo / próximo:** ítems `'proximamente'`, placeholders o stubs sin lógica real.
